# Bukti

Satu folder untuk setiap langkah kerja, berurutan dari merencanakan sampai menjalankan. Nomor folder adalah urutan kerja; kode unit ada di baris pertama README setiap folder.

Setiap README menjawab empat hal:

1. **Pertanyaan apa yang dijawab langkah ini?** Sudah ditulis, ubah bila perlu.
2. **Apa yang saya kerjakan?** Dua atau tiga kalimat dengan kata-kata sendiri.
3. **Bukti per elemen.** Satu baris per elemen unit: yang dikerjakan, berkas buktinya, jenis bukti, status.
4. **Catatan terbuka.** Yang belum selesai, ditulis apa adanya.

## Aturan bukti (Pedoman BNSP 301-2013)

| Aturan | Pertanyaan pemeriksa |
| --- | --- |
| Valid | Apakah bukti ini menjawab elemen yang dinilai? |
| Asli | Apakah ini pekerjaan saya sendiri, dan dapat saya jelaskan tanpa membaca? |
| Terkini | Apakah bukti menyebut tanggal jalan atau tanggal keputusan? |
| Memadai | Apakah setiap elemen punya sedikitnya satu bukti? |

## Jenis bukti

- **L, langsung:** artefak yang berjalan dan dapat didemonstrasikan (kode, job, layanan).
- **TL, tidak langsung:** hasil terukur dan laporan (ringkasan JSON, laporan uji).
- **T, tambahan:** dokumen tata kelola, surat, keterangan pihak ketiga.

## Surat

Surat izin sumber data dan berkas etik ditempatkan di `surat/` bila sudah ditulis ulang.
