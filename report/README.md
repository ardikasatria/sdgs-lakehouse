# Laporan

Laporan portofolio ditulis per bab dalam Markdown dan digabung dengan `make laporan`. Bab 3 mengikuti urutan folder `bukti/`, sehingga laporan dan bukti dapat dibaca berdampingan.

| Berkas | Bab | Isi |
| --- | --- | --- |
| `01-pendahuluan.md` | 1 | asesi, skema, unit, cara membaca laporan, pernyataan penggunaan asisten AI |
| `02-proyek.md` | 2 | persoalan "satu angka, banyak versi", organisasi, sumber, arsitektur |
| `03-bukti-per-langkah.md` | 3 | sebelas langkah, satu subbab per folder `bukti/` |
| `04-hasil-dan-masalah.md` | 4 | hasil terukur dan insiden beserta perbaikannya |
| `05-keterbatasan.md` | 5 | yang belum terbukti dan rencana penyelesaiannya |
| `06-lampiran.md` | Lampiran | perintah bangun ulang, daftar berkas |
